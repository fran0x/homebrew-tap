# fran0x/tap

Homebrew formulae for [fran0x](https://github.com/fran0x) projects.

```sh
brew install fran0x/tap/den   # installs den (read-only) and dew (with changes)
```

| Formula | Project |
| --- | --- |
| `den` | [Den](https://github.com/fran0x/den): a terminal inspector for your developer machine |

Formulae install the release binaries for macOS and Linux (Intel and ARM). `Formula/den.rb`
is generated by `just tap` in the Den repository after each release; edit it there.
